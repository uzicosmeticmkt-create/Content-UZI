## คลิป 1 — ถูกรุม → ปาดเดียว (13s)

```
参考说明：图1、图2只用于女主角的身份：脸部、向后梳紧的光滑马尾、珍珠耳环；不参考图中的服装、背景和文字。图3是口红产品UZI LIP MATTE：透明方形瓶身、透明瓶盖、金色环、珊瑚粉色膏体、金色竖排“UZI”字样。图4是该口红的刷头：水滴形植绒海绵刷头。

竖屏电影质感美妆广告，真实摄影风格。新闻发布厅内，女主角（图1）穿奶油色修身西装外套，被二十多名穿深色衣服的记者和摄影师紧紧围住。整体冷灰蓝色调，硬朗的白色闪光灯。

[0-2秒] 正上方俯拍：记者围成密集的圆圈，女主角站在正中央，显得很渺小，闪光灯此起彼伏。镜头缓慢下降。快门连拍声和重叠的嘈杂人声。

[2-3.5秒] 硬切，女主角的主观视角：十几支话筒同时伸向镜头，闪光灯刺眼，手持镜头轻微晃动。一名男记者大喊：“CEO อายุน้อยที่สุด กดดันไหมครับ!” 一名女记者抢着问：“คิดว่าตัวเองเก่งพอเหรอคะ?”

[3.5-5秒] 硬切，女主角脸部近景：嘴唇是苍白的裸色、略干、没有口红。她张嘴想回答，小声说：“ค่ะ… ดิฉัน…” 声音中断，喉咙吞咽一下。周围声音变闷，心跳声变大。

[5-6秒] 硬切，手部特写：她紧握发言稿，纸被捏皱，手指微微发抖。

[6-7.5秒] 硬切，电视摄像机镜头玻璃的特写：玻璃上映出她弯曲的倒影，脸色苍白、显得渺小。她的眼睛盯着自己的倒影。

[7.5-9秒] 中景：周围所有记者瞬间静止定格，闪光灯的光团凝固在空中，只有她在动——她从西装口袋里取出图3的口红。所有声音消失，只听到旋开瓶盖的一声清脆“咔”。

[9-10秒] 微距：她把刷杆从瓶中抽出，图4的水滴形海绵刷头上沾满珊瑚粉色膏体，瓶身金色UZI字样清晰可见。

[10-11.5秒] 嘴唇微距慢动作：她以摄像机镜头的倒影为镜子，从唇中向嘴角一笔涂开，珊瑚粉哑光色完全覆盖苍白的唇色。

[11.5-13秒] 嘴唇特写：她抿唇一次，哑光妆效定型；焦点从嘴唇移到眼睛，她抬眼直视前方，眼神平静而坚定。定格解除，现场嘈杂声和一记低沉鼓点同时猛然回来。

连续性：涂口红之前嘴唇始终苍白无色，涂完之后始终是均匀的珊瑚粉哑光色。画面中只有图3这一支口红。
排除：画面中不要出现字幕和任何文字，不要出现其他品牌标志；她不哭泣，不做夸张表情。
```

## คลิป 2 — คุมเวที (10s)

```
参考说明：图1、图2只用于女主角的身份：脸部、向后梳紧的光滑马尾、珍珠耳环；不参考图中的服装、背景和文字。图3是口红UZI LIP MATTE的唇色参考：珊瑚粉色。

竖屏电影质感美妆广告，真实摄影风格。同一个新闻发布厅，紧接上一段：女主角（图1）穿奶油色修身西装外套，嘴唇已涂上均匀的珊瑚粉哑光口红，口红已收回口袋。前方是一个木质讲台，台上插着一排话筒，旁边放着一杯透明玻璃杯装的水。从这一段开始，女主角身上有温暖的金色主光，周围记者仍是冷灰色调。

[0-2.5秒] 正面跟拍慢动作，镜头在她前方后退：她稳步走向讲台，原本伸向她的话筒纷纷后撤，记者们向两侧让开一条通道，表情从咄咄逼人变成愣住。一名男记者低声说：“…เดี๋ยวนะ” 配乐逐渐增强。

[2.5-4.5秒] 硬切，脸部近景：一名摄影师在很近的地方连闪三次闪光灯，她不眨眼，直视前方；珊瑚粉嘴唇在强闪光下依然哑光、均匀、不反光、不结块。三声快门正好落在鼓点上。

[4.5-6.5秒] 硬切，讲台中景：她拿起透明玻璃杯喝一口水，再放回讲台，发出清脆的“叮”。硬切杯口特写：杯沿干净透明，没有任何口红印。

[6.5-8秒] 硬切，近景：她身体前倾靠近讲台上的话筒，嘴角微微上扬，平静、清晰、不急不慢地说：“ถามมาได้เลยค่ะ” 在她开口前，音乐突然停止。

[8-10秒] 硬切，从她身后拍的大全景：她站在讲台后，整个发布厅的记者慢慢放下相机和话筒，安静而专注地看着她。全场安静。

连续性：嘴唇始终是均匀的珊瑚粉哑光色；服装、发型、珍珠耳环与上一段一致。
排除：画面中不要出现字幕和任何文字，不要出现其他品牌标志，玻璃杯上不能有口红印。
```
