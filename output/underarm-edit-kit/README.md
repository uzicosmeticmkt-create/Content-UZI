ใช้คู่กับคลิปลิปซิงค์นางแบบจาก Fuzion (OmniHuman 2.0) ใน CapCut ได้เลย

## ไฟล์ในชุดนี้
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `01_hook_0-3s.png` … `06b_price_25-30s.png` | ป้ายข้อความโปร่งใสขนาด 1080x1920 วางทับเต็มจอได้เลย |
| `broll_product_3s.mp4` | ซองสินค้าซูมเข้าช้าๆ บนพื้นชมพู |

## ไทม์ไลน์ (ขยับเวลาให้ตรงกับเสียงจริง)
| เวลา | ภาพหลัก | ป้ายข้อความ | ลูกเล่นให้คนหยุดดู |
|---|---|---|---|
| 0–3s | นางแบบพูด | `01_hook` | เปิดด้วยซูมเร็ว 110% → 100% ใส่เสียง "ติ๊ง" |
| 3–8s | นางแบบพูด | `02_pain` | ตัดภาพซูมเข้าหน้า 1 ครั้ง (jump cut) |
| 8–11s | **`broll_texture`** (เสียงพูดยังวิ่งต่อ) | `03_howto` | เสียง ASMR บีบครีมเบาๆ |
| 11–14s | นางแบบพูด | `03_howto` | — |
| 14–17s | **`broll_product`** | `04_ingredients` | ป้ายเด้งเข้า (pop-in) |
| 17–25s | นางแบบพูด | `05_result` (ตั้งแต่ 19s) | ซูมช้าๆ ตลอดช่วง |
| 25–30s | นางแบบพูด | `06b_price` + `06_cta` | ป้าย CTA กระพริบเบาๆ + ลูกศรชี้ลงคอมเมนต์ |

**คำแนะนำเพิ่ม**
- ใส่ซับไตเติลอัตโนมัติของ CapCut ตัวเล็กไว้ด้านล่าง (คนดูส่วนใหญ่ปิดเสียง)
- เพลงประกอบเบาๆ แนวหรู ลดเสียงเพลงลงเหลือ -20dB ให้ได้ยินเสียงพูดชัด
- ห้ามวางข้อความไว้ต่ำกว่า 1/4 ล่างของจอ เพราะจะโดนปุ่มและแคปชั่นของ TikTok/Reels บัง
- ถ้ามีคลิปจริงตอนนางแบบทาเอง ให้ใส่แทน `broll_texture` ช่วง 8–11s จะได้ความน่าเชื่อถือมากกว่า
